# MCP parity ledger

Source: `ares-64` commit `1c9b9637476a83f7b80d3db1115a0f71529820d9`, `tools/mcp/ares_mcp.py`.
The [machine-readable inventory](mcp/parity-ledger.json) freezes all 68 decorated
tool signatures, annotations, required flags, defaults and behavioral docstrings,
with the source SHA-256 and line numbers. It records backend dependencies and
per-tool evidence/limits. Generated FastMCP 1.30.0 input schemas and the actual
stdio registry now verify all **68 names and parameter signatures**, including
defaults/nullability. Full validation differences (bounds, specific enums,
unknown-field policy and nested shapes) are checked in under `tests/reference/`.

All 68 names retain native/service implementations and successful actual stdio
runtime evidence in `tests/reference/task-9-tool-coverage.json`. The port uses
its own versioned internal service/result contract with session/epoch identities,
bounded pages and explicit truncation/errors. These intentional adapter changes
are documented with tests; no tool was removed and legacy TCP compatibility is
not advertised. The reference bridge is not a shipped dependency. See the final
task 9 execution-log entry for fixture, game, Electron and copied-package gates.
The task 6 physical-device/audible checks remain separate manual gates.
