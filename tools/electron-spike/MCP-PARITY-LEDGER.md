# MCP parity ledger

Source: `ares-64` commit `1c9b9637476a83f7b80d3db1115a0f71529820d9`, `tools/mcp/ares_mcp.py`.
The [machine-readable inventory](mcp/parity-ledger.json) freezes all 68 decorated
tool signatures, annotations, required flags, defaults and behavioral docstrings,
with the source SHA-256 and line numbers. It records backend dependencies and
per-tool evidence/limits. FastMCP-generated JSON Schema parity is **not run**;
that comparison belongs to the adapter work. No Python dependency ships here.

Native session services do not constitute an implemented MCP tool. All 68 tools
remain unavailable through MCP until their adapter and backend gates pass.
